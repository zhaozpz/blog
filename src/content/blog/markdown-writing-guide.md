写博客只需要 Markdown 的一个很小的子集。这篇把最常用的语法列全，当作速查表。

## 标题

用 `#` 号，层级从 `##` 开始用即可（文章标题由 frontmatter 的 `title` 提供）：

```md
## 二级标题
### 三级标题
```

## 强调

- **加粗**：`**文字**`
- *斜体*：`*文字*`
- `行内代码`：用反引号包住

## 列表

无序列表用 `-`：

```md
- 第一项
- 第二项
  - 缩进两格表示子项
```

有序列表直接写数字：

```md
1. 第一步
2. 第二步
```

## 代码块

用三个反引号，并注明语言以获得语法高亮：

````md
```ts
function add(a: number, b: number): number {
  return a + b;
}
```
````

渲染效果：

```ts
function add(a: number, b: number): number {
  return a + b;
}
```

## 引用

用 `>`：

```md
> 过早优化是万恶之源。 —— Donald Knuth
```

> 过早优化是万恶之源。 —— Donald Knuth

## 链接和图片

```md
[链接文字](https://example.com)
![图片说明](./images/photo.png)
```

图片建议放在文章同级目录或统一的 `src/assets/` 下。

## 表格

```md
| 左对齐 | 居中 | 右对齐 |
| :----- | :--: | -----: |
| 1      |  2   |      3 |
```

| 左对齐 | 居中 | 右对齐 |
| :----- | :--: | -----: |
| 1      |  2   |      3 |

## 分隔线

三个短横线：

```md
---
```

日常写作掌握这些就足够了。
